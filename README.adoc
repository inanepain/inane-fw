= Introduction

The aim of this site is to further the inanepain libraries and create a standard application template/skeleton that supports console and web. A big part of this is to standardise the directory structure.

== Directory Structure

Currently, everything is in one big mixing bowl, which is not a problem for the code, but not so easy to follow as a human.

= Structure

The basic contents for the directories.

== config

Configuration files, generally of a global nature, i.e. files that effect the whole site / all modules.

== data

Commonly used to store any sqlite databases or files to create / update any databases.

== filesrv

Files for client downloading.

== lib

The inanepain library files.

== public

Web server root.

== src

Sites main source code.

== source

Code for additional components.

=== source/doc

Asciidoc files that build the README and CHANGELOG.

=== source/image

Custom images for the site.

=== source/lib

Inanepain development area for new features or just something you are not sure of as yet and might scrap.

=== source/style

Stylesheet source files.

== vendor

Composer libraries.
