= Introduction

The aim of this site is to further the inanepain libraries and create a standard application template/skeleton that supports console and web. A big part of this is to standardise the directory structure.

== Directory Structure

Currently, everything is in one big mixing bowl, which is not a problem for the code, but not so easy to follow as a human.

= Develop

Since this is more of a *development* project, it is most likely that you'd want to *checkout* the code rather than use *composer* to install it.

== Setup

To get the code with all and sundry, use git.

.Clone & enter the repository
[source,shell]
----
git clone ssh://philip@blackbetty.local:2222/skeleton/inane-fw.git
cd inane-fw
----

Next up is to get all inane libraries.

.Init submodules
[source,shell]
----
git submodule update --init --recursive
----

This leaves one last step in the setup process, set the _submodules_ to track the *branch* "develop"

.Track & fetch develop
[source,shell]
----
# update the tracked branch
for d in lib/inanepain/*; do git submodule set-branch -b develop $d; done

# fetch the latest commits on the branch
git submodule update --remote --recursive
----

That's the setup done.

= Structure

The basic contents for the directories.

== config

Configuration files, generally of a global nature, i.e. files that affect the whole site / all modules.

== data

Commonly used to store any sqlite databases or files to create / update any databases.

== filesrv

Files for client downloading.

== lib

The inanepain library files.

== module

Sites main source code.

== public

Web server root.

:leveloffset: +1

= source

Code for additional components.

:leveloffset: +1

= database

Stores the DDL for the project's databases. Thus keeping changes tracked in git. Each connection should have its own directory under which schemas, tables and sundry are contained.

[source,text]
----
├──  database/ <1>
│   └──  inane-fw/ <2>
│       └──  main/ <3>
│           ├──  __mobile_app_scripts__.sql <4>
│           ├──  departments.sql
│           ├──  divinations.sql
│           ├──  formulas.sql
│           ├──  fortunes.sql
│           ├──  sqlean_define.sql
│           ├──  students.sql
│           ├──  update_timestamp.sql
│           └──  users.sql
----
<1> Root of database DDL files.
<2> Connection name.
<3> Schema.
<4> Table, view, trigger, function, ... scripts.

:leveloffset: 2

== doc

AsciiDoc files that build the project README and CHANGELOG.

== image

Custom images for the site.

== lib

Development area for new, overriding or extending libraries. It can also be a bit of a playground to experiment with various ideas.

== style

Stylesheet source files.
