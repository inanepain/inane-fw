== Versioning

I've finally hit upon an idea that I believe will make it easier to handle the versions for Classes.

My current issue is that I bump the version when making a change, then, when next I change the file, I bump it again because I'd forgotten it’d been bumped already, or the other way round.

.version bump process
* When I make changes to a file, I give it a *TODO* labelled *version bump*
* When I create a release, I close the todos and bump the version at the same time
