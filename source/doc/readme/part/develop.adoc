= Develop

Since this is more of a *development* project, it’s most likely that you'd want to *check out* the code rather than use *composer* to install it.

== Setup

To get the code with all and sundry, use git.

.Clone & enter the repository
[source,shell]
----
git clone ssh://philip@blackbetty.local:2222/skeleton/inane-fw.git
cd inane-fw
----

Next up is to get all inane libraries.

.Init submodules
[source,shell]
----
git submodule update --init --recursive
----

This leaves one last step in the setup process, set the _submodules_ to track the *branch* "develop"

.Track & fetch develop
[source,shell]
----
# update the tracked branch
for d in lib/inanepain/*; do git submodule set-branch -b develop $d; done

# fetch the latest commits on the branch
git submodule update --remote --recursive
----

That's the setup done.
